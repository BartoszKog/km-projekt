# Projekt analizy komunikacji KML

Projekt analizy komunikacji KML, który składa się z notebooków i modułów. Dane pochodzą z GTFS dostarczanych przez Koleje Małopolskie.

## Przygotowane notatniki

- `marey_chart.py` - notebook z kontrolką kolejowego wykresu ruchu, która pozwala na interaktywne przeglądanie kursów i stacji. [link do aplikacji](https://molab.marimo.io/notebooks/nb_E3J9uiYFDHa5jCWWq7p5ck/app)
- `data_prep.py` - notebook z przygotowaniem danych do analizy. [link do notatnika](https://molab.marimo.io/github/BartoszKog/km-projekt/blob/main/notebooks/data_prep.py)

## Przygotowane moduły
