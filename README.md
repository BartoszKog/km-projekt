# Projekt analizy komunikacji KML

Projekt analizy komunikacji KML, który składa się z notebooków i modułów. Dane pochodzą z GTFS dostarczanych przez Koleje Małopolskie.

## Przygotowane notatniki

- `marey_chart.py` - notebook z kontrolką kolejowego wykresu ruchu, która pozwala na interaktywne przeglądanie kursów i stacji.
- `data_prep.py` - notebook z przygotowaniem danych do analizy.

## Przygotowane moduły

- `marey_viz.py` - moduł z kontrolką kolejowego wykresu ruchu, która pozwala na interaktywne przeglądanie kursów i stacji.
